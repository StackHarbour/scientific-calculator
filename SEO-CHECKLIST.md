# SEO launch checklist

The application already includes the technical pieces in code. Before launch:

- Set the production domain/canonical URL.
- Verify `/robots.txt`.
- Verify `/sitemap.xml` and that it contains only canonical indexable URLs.
- Verify every important route has a unique title and description.
- Inspect rendered HTML for the H1 and useful page content.
- Run the deployed pages through Google's URL Inspection tool.
- Run structured data through Google's Rich Results Test where applicable.
- Submit the sitemap in Google Search Console.
- Verify mobile usability and Core Web Vitals after deployment.
- Customize the legal pages with the site's actual owner/contact details before public launch.
- If analytics or advertising is added later, update the privacy policy and consent behavior as required.
